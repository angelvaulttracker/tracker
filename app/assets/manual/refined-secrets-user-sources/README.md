# Refined regular-series supplied secrets

Thirteen figures from eleven supplied clipboard images: Robby Angel for
Animal Ver. 1–4, Marine, Flower, Vegetable, and Sweets; Unicorn, Turtle,
Bee, Shiitake, and Patissier. Source names and crops are recorded in
`scripts/photo_batches/refined-secrets.json`; original photos are retained
under ignored deliverables. Robby pedestals and Turtle shell are preserved.

Only refined IDs on pages 10–17 are updated. Unrefined figures on pages
18–21 remain separate and unchanged. All existing collection IDs remain.
Local u2net masks preserve source RGB and print texture without generation
or upscaling. Per-asset provenance is in `sources.json`.
