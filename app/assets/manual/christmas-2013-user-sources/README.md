# Christmas Series 2013 supplied photo cutouts

Six transparent PNGs from two user-supplied photos: regular Santa Claus, Snowman,
Reindeer and Gingerbread Man; plus pink secret Santa Claus and Reindeer. Only
front-facing regular figures are used, excluding the rear-view photographs and
labels. The source calls Reindeer Moose; the existing catalog name is retained.

Local background removal preserves original RGB and source resolution. No figure
pixels were generated. The regular Reindeer antlers and Snowman white body/feet
are restored with traced alpha contours revealing original source pixels. These
corrections are recorded in `scripts/photo_batches/christmas-2013.json` so they
survive regeneration. Source filenames, crops and dimensions are in `sources.json`.

The sources are small (425x722 and 300x400). Higher-resolution photos can replace
these assets later while preserving the existing catalog IDs and secret flags.
