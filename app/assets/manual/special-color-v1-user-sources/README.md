# Animal Ver. 1 Special Color supplied photos

Twelve regulars and the pink Chipmunk secret extracted from the supplied
`codex-clipboard-e81c395c-8743-43ba-8f54-0265d3b8ecb1.png`.
The source is preserved as `special-color-v1-lineup.png` under ignored
`deliverables/special-color-v1-cutouts/source-photos/`.

Local u2net masks preserve original photo RGB and print texture without
generation, recoloring, or upscaling. Chipmunk uses the pictured side view.
Reproducible crops are in `scripts/photo_batches/special-color-v1.json`;
provenance is in `sources.json`. Existing catalog IDs are preserved.
