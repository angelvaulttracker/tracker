# ISETAN Display Special Color supplied photos

All fifteen figures extracted from the supplied
`codex-clipboard-b9a68e29-2d08-4ad9-83e9-75284e2ef865.png`.
The original is preserved as `isetan-lineup.png` under ignored
`deliverables/isetan-cutouts/source-photos/`.

Local u2net masks retain original RGB and printed photo texture without
generation, recoloring, or upscaling. Each named color and the winking Owl
are mapped separately to existing IDs. Reproducible settings are in
`scripts/photo_batches/isetan.json`; provenance is in `sources.json`.
The dark-blue Starfish headpiece uses a traced alpha restoration recorded
in the manifest; its original photo pixels are retained.
