# Unrefined regular-series secrets

15 transparent cutouts from user-supplied guidebook photographs, processed locally with cached u2net weights. Original RGB is preserved; no generated artwork.

Animal versions 1–4, Marine, Fruit, Flower, and Vegetable variants are assigned only to their unrefined catalog IDs. Refined artwork remains separate. Crop coordinates and source filenames are recorded in sources.json and scripts/photo_batches/unrefined-secrets.json.
