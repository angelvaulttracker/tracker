# Ornament and Valentine secret variants

Six supplied guidebook cutouts: Christmas Ornament 2023 Lop Ear Rabbit, Valentine 2019 Chocolate Rabbit and Chocolate Robby Angel, and Valentine 2017 Teddy Bear, Sweet Kitty and Robby Plushie Angel. Local cached u2net preserves source RGB. These update secret entries only; regular versions retain their own artwork. Source/crop provenance: sources.json. Manifest: scripts/photo_batches/ornament-valentine-secrets.json. Originals and previews: ignored deliverables/ornament-valentine-secrets.

The ornament hanging loop is restored with an explicit alpha polygon in the manifest.
