# Chinoiserie supplied photos

Six regular figures from `img_chinoiserie_2020_01.png`, Lantern Dragon
from `images (20).jpeg`, and Lantern Robby Angel from `images (19).jpeg`.
Robby retains the photographed lantern pedestal.

Local u2net background removal preserves original RGB pixels without
generation or upscaling. The Kite Cockerel and Tiger-like Cap masks include
traced erasures of attached poster background. Reproducible crops and alpha
corrections are in `scripts/photo_batches/chinoiserie.json`; provenance is
in `sources.json`. Originals and previews stay in ignored deliverables.
