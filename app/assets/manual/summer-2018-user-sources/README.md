Eight regular figures extracted from the user-supplied clipboard lineup
`codex-clipboard-77b39251-0ea1-4259-aece-3072220056db.png`.
The original is preserved as `summer-2018-lineup.png` under ignored
`deliverables/summer-2018-cutouts/source-photos/`.

Local u2net segmentation preserves original RGB, including the printed
photo texture; no generation, recoloring, or upscaling. Crops are stored in
`scripts/photo_batches/summer-2018.json`; provenance is in `sources.json`.

`codex-clipboard-817845b6-c415-4803-ba45-30b72a9400b0.png` is preserved as
`summer-2018-extra-lineup.png` alongside the first. It supplies Gray Pants,
Purple Pants, Yellow T-shirt, Blue T-shirt, Sailor, and Ocean Robby Angel
(including its pedestal), completing artwork for all fourteen existing entries.
The pictured binocular accessories/side-view example are not additional
catalog entries and are not substituted for any front-view figure.
