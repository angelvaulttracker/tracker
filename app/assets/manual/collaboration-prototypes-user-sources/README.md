# Collaboration and prototype user photographs

41 transparent cutouts from ten user-supplied guidebook photographs. Processed locally with cached u2net weights, preserving source RGB without image generation. Source originals are saved in deliverables/collaboration-prototype-cutouts/source-photos. Crop coordinates and alpha corrections are recorded in scripts/photo_batches/collaboration-prototypes.json; sources.json records provenance.

Includes Collectors Trophy Special Color 2014 (5), Hong Kong Rabbit (1), non-ornament Ladurée Mini Marie-Antoinette (1), NYLON 10th Anniversary Rabbit replacement (1), Francfranc 20th Anniversary (7), Prototypes (11), Jet 7th Anniversary (1), Good Feel sheep (3), L’Occitane Rose (4), and 6 University Series Prototype including Pass (7). Existing IDs and variant-specific Secret labels are preserved. The ornament Mini Marie-Antoinette and NYLON 15th Anniversary artwork are unchanged.
