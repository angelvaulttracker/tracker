# Workshop and accessories supplied photographs

81 transparent PNGs cropped from 11 user-supplied guidebook photographs. Processed locally using cached u2net, preserving source RGB. Pale hats, cow horns and the rabbit strap have explicit alpha restorations in `scripts/photo_batches/workshop-accessories.json`. Disconnected sticker and accessory parts are retained. Sources and crop provenance are recorded in `sources.json`; originals and previews remain in ignored `deliverables/workshop-accessories-cutouts`. Costume artwork uses standalone front views.
