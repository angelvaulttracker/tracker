# Animal Series Ver. 3 Special Color supplied photo cutouts

Twelve transparent PNGs extracted locally from the supplied two-row lineup:
French Bulldog, Duckbill, Lop Ear Rabbit, Owl, Hippopotamus, Zebra, Alpaca,
Buffalo, American Short Hair, Gorilla, Chameleon and Parrot. Source colors,
lettering-free figure details and source resolution are preserved. Lineup
captions are excluded by the crop boxes. No generative image services were used.

Mapped only to existing Animal Series Ver. 3 Special Color IDs. The existing
Unicorn entry is not pictured and remains unchanged. Catalog IDs and collection
data are preserved; source-label typos are not copied into catalog names.

The incremental batch is `scripts/photo_batches/special-color-v3.json`.
Original filename, crop boxes and output dimensions are in `sources.json`.
