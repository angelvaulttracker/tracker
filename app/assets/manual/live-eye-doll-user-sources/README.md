# Live-Eye Doll Costume supplied photos

All fifteen costumes from supplied clipboard images
`f9f426a8-e28a-4ab5-827a-dc341fe44f48` (2006–2009) and
`a52ea0ee-b179-4a48-a06d-c5ee9e27fdb8` (2009–2013).
Originals are preserved in ignored
`deliverables/live-eye-doll-cutouts/source-photos/`.

Repeated names represent different outfits: Rabbit 2006 is a pink headpiece;
Rabbit 2010 has white or pink full-body costumes. Panda 2007 is a headpiece;
Panda 2009 is a full-body suit. Tiger 2008 is a yellow headpiece; Tiger 2009
is an orange full-body suit. All existing IDs are preserved.

Local u2net masks preserve original RGB and print texture without generation,
recoloring, or upscaling. Crops and alpha corrections are recorded in
`scripts/photo_batches/live-eye-doll.json`; provenance is in `sources.json`.
