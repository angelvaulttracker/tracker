# MODI Beauty Flowers supplied photo cutouts

Six transparent PNGs from the user-supplied B E A U T Y lineup, linked to the
existing MODI Collaboration Series 2014 entries: Cherry Blossom, Cactus, Rose,
Carnation, Morning Glory and Lily Bell. The catalog ID/name spelling Cheery
Blossom is preserved, as are all other IDs and collection data.

Local background removal retains original RGB, lettering and source resolution.
No generative image services were used. The Morning Glory white-and-gold tip is
restored with a traced alpha contour revealing the source photo's original
pixels. The correction is recorded in `scripts/photo_batches/modi-beauty-flowers.json`.
Source filenames, crop boxes and dimensions are in `sources.json`.
