# Gift and seasonal secrets

Nine user-supplied guidebook cutouts, processed locally with cached u2net weights and original RGB. No generated artwork. Sources and crop coordinates are recorded in sources.json and scripts/photo_batches/gift-mixed-secrets.json.

Includes Flower Gift, Birthday Gift Bear, standard Sky Color Aurora (not the Special Edition), Special Cake, Mexican Cactus, Ice, and Happiness. Existing catalog IDs are preserved; the Rainbow Sunflower Robby display name follows the photograph. Sunflower Lion Rainbow follows Rose Lion Pink in catalog order.
